Core Capabilities

Everything needed for Vanilla, Fabric, and Forge cleanly isolated.

Designed around clean per-loader mod isolation, built-in Modrinth v2 discovery, and cryptographic verification without bloat.

Vanilla · Fabric · Forge

Isolated Loader Profiles

Switches seamlessly between Vanilla, Fabric, and Forge across 1.21.4–1.16.5 with isolated mods/ folders and shared saves, shaderpacks, resourcepacks, and options.txt.

Modrinth v2 API

Modrinth Library & Shader Kits

Browse Mods, Shaders, and Resource Packs directly, install 1-click Fabric (Sodium+Iris+Lithium) or Forge (Embeddium+Oculus) kits, or import local OptiFine .jar/.zip files.

Temurin 21 · ZGC

Auto Java 21 & Hardware Tuning

Installs verified Eclipse Temurin 21 without admin rights and reads CPU, RAM, and DirectX 12 GPU tier to calibrate -Xmx heap, G1GC/ZGC flags, and options.txt.

64×64 & 64×32 PNG

Local PNG Skins (Slim & Classic)

Imports any 64×64 or legacy 64×32 PNG skin with Slim (3 px) or Classic (4 px) arms, previews in 3D, and packages it into a native Vanilla resource pack on launch.

Protocol 769

Worlds & Local Server Quick Play

Manage singleplayer saves, ping local offline-mode (online-mode=false) development servers via Protocol 769 SLP, and jump straight in with Quick Play.

SHA-1 / 256 / 512

Path-Safe & Hash-Verified

Verifies Mojang, Temurin, and Modrinth files cryptographically before execution and auto-routes caches into ASCII-safe paths on Windows PCs with special characters.

What happens if Java 21 is not installed on another PC?

Click "Auto-Install Java 21" inside Basalt. It downloads official Eclipse Temurin 21, checks the SHA-256 hash, and extracts it into Basalt's runtime folder without needing administrator permissions.

How do Fabric, Forge, and OptiFine stay separated?

Basalt keeps separate per-version mods folders for Fabric and Forge so loader JARs never conflict, while sharing saves/, shaderpacks/, resourcepacks/, screenshots/, and options.txt cleanly.

How do offline PNG skins work without mods?

Basalt validates your 64×64 or 64×32 PNG skin, aligns the offline player UUID with your chosen Slim (3 px) or Classic (4 px) arm model, and writes a native Vanilla resource pack (basalt_skin.zip).

Why does Windows SmartScreen appear on pre-release builds?

Open-source pre-releases compiled by GitHub Actions are not yet signed with a paid Authenticode certificate. Always verify SHA256SUMS.txt on GitHub Releases before running.
