Sık Sorulanlar

Java 21 bilgisayarımda yoksa oyunu nasıl açıyor?

Sistemde Java 21 veya üzeri bulunamazsa uygulama içinden "Java 21 Kur" düğmesine tıklaman yeterlidir. Basalt, Windows'un yerleşik aracıyla Adoptium Temurin 21 paketini indirir, SHA-256 ile doğrular ve yerel çalışma klasörüne kurar.

Windows SmartScreen veya antivirüs uyarısı neden görünebilir?

Yeni yayınlanan ve ücretli kod imzalama sertifikası taşımayan bağımsız açık kaynak .exe dosyaları ilk haftalarda Windows SmartScreen tarafından tanınmayabilir. Açık kaynak kod, GitHub Releases dağıtımı ve sayfadaki SHA-256 doğrulama koduyla dosyanın değişmediğini kontrol edebilirsin.

Özel skin ve FPS HUD ayarlarım oyuna nasıl yansır?

Basalt içinden yüklediğin 64x64 veya 64x32 PNG skinler ve seçtiğin Slim (3 px) / Classic (4 px) kol modeli doğrudan Minecraft 1.21.4 Fabric istemci moduna aktarılır. Sol üstteki anlık FPS HUD katmanını da isteğine göre açıp kapatabilirsin.

Hangi oyun modları ve sunucular destekleniyor?

Basalt; yerel tek oyunculu kayıtlar ve yerel online-mode=false geliştirme sunucuları için tasarlanmıştır. Microsoft çevrimiçi hesap doğrulamasını atlatmaz.
