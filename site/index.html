Core Capabilities

Everything needed to run Vanilla 1.21.4 cleanly.

Designed around a calm, single-focus workflow without mod-loader conflicts, background bloat, or complicated setup steps.

java.exe · Direct

Pure Official Vanilla 1.21.4

Downloads and SHA-1 verifies the official Mojang 1.21.4 client JAR, libraries, and asset index, launching directly without Fabric or Forge overhead.

Temurin JDK 21

Automatic Java 21 Setup

If Java 21 is missing on the PC, Basalt downloads Eclipse Temurin 21 via Windows curl.exe, verifies its SHA-256 hash, and installs it locally without admin rights.

G1GC / ZGC

Hardware-Calibrated Settings

Detects CPU cores, RAM, and DirectX 12 GPU tier on startup to configure -Xmx heap allocation, garbage collector flags, and options.txt render distance.

64×64 & 64×32 PNG

Local PNG Skins (Slim & Classic)

Imports any 64×64 or legacy 64×32 PNG skin with Slim (3 px) or Classic (4 px) arms and packages it into a native Vanilla resource pack on launch.

Protocol 769

Worlds & Local Server Quick Play

Manage singleplayer saves, ping local offline-mode (online-mode=false) development servers via Protocol 769 SLP, and jump straight in with Quick Play.

ASCII-Safe Cache

Portable & Path-Safe on Any PC

Automatically routes runtime caches to an ASCII-safe directory when the Windows username contains spaces or non-ASCII characters, preventing JVM launch errors.

What happens if Java 21 is not installed on another PC?

Click "Auto-Install Java 21" inside Basalt. It downloads official Eclipse Temurin 21, checks the SHA-256 hash, and extracts it into Basalt's runtime folder without needing administrator permissions.

Why does Basalt launch pure Vanilla instead of Fabric?

Launching official Vanilla 1.21.4 directly via java.exe eliminates Mixin/loader classpath conflicts and Gradle daemon overhead, starting the game faster and reliably on every machine.

How do offline PNG skins work without mods?

Basalt validates your 64×64 or 64×32 PNG skin, aligns the offline player UUID with your chosen Slim (3 px) or Classic (4 px) arm model, and writes a native Vanilla resource pack (basalt_skin.zip).

Which servers are supported?

Singleplayer worlds and local/LAN development servers running with online-mode=false. Servers requesting Microsoft EncryptionRequest are never bypassed.
