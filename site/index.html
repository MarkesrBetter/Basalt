Frequently Asked Questions

How does Basalt launch the game if Java 21 is missing?

If no Java 21 or newer JDK is found on the PC, click Auto-Install Java 21 inside the app. Basalt downloads Eclipse Temurin 21 via Windows built-in curl.exe, verifies the SHA-256 checksum, and extracts it into its local data folder without admin elevation.

Why might Windows SmartScreen or antivirus flag a fresh binary?

Newly released open-source .exe binaries without a paid EV code-signing certificate can trigger unfamiliar-publisher prompts during their first days online. You can inspect the public source code, GitHub Releases asset, and verify the exact SHA-256 digest above before running.

How are local skins and the FPS HUD passed to Minecraft?

Any 64x64 or 64x32 PNG skin imported into Basalt and your chosen Slim (3 px) or Classic (4 px) arm model are injected directly by the bundled Fabric 1.21.4 Mixin mod, alongside the toggleable in-game FPS HUD overlay.

Which worlds and servers are supported?

Basalt supports singleplayer worlds under local saves and offline-mode (online-mode=false) development servers. Official Microsoft account authentication is never bypassed.
