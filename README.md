# Basalt

> **Disclaimer:** *NOT AN OFFICIAL MINECRAFT PRODUCT. NOT APPROVED BY OR ASSOCIATED WITH MOJANG OR MICROSOFT.*

Native Windows 10/11 desktop launcher powered by **Tauri 2 + TypeScript WebUI** and a **Rust** core for **Minecraft Java Edition (`1.21.4` – `1.16.5`)** with isolated **Vanilla, Fabric, and Forge** profiles and built-in **Modrinth v2** integration.

## Features (`v0.3.0 Pre-release`)

- **Isolated Vanilla / Fabric / Forge Loader Profiles:** Switch cleanly per version while keeping loader-specific `mods/` isolated (`loader_mods/fabric/<ver>` via `-Dfabric.modsFolder` and `profiles/forge/<ver>/mods`) and sharing `saves/`, `shaderpacks/`, `resourcepacks/`, `screenshots/`, `options.txt`, and `servers.dat` via NTFS directory junctions.
- **Built-in Modrinth v2 Library:** Search & browse **Mods**, **Shaders**, and **Resource Packs**, sort by Downloads / Relevance / Follows / Updated, see installed badges, and automatically install required mod dependencies (such as Fabric API) with cryptographic hash checks.
- **1-Click Shader & FPS Kits:** Install curated **Fabric** (`Fabric API` + `Sodium` + `Iris Shaders` + `Lithium` + `Complementary Unbound`) or **Forge** (`Embeddium` + `Oculus` + `Complementary Unbound`) packs in a single click directly from Modrinth.
- **OptiFine & Custom File Manager:** Import your own locally downloaded `.jar` mods (including OptiFine) or `.zip` shader/resource packs, and toggle `.disabled` state or remove items from the **Installed** tab.
- **Single-Binary Portable Windows App (`basalt.exe`):** Runs without an installer wizard across 15 Minecraft Java releases (`1.21.4` down to `1.16.5`), SHA-1 verifying official Mojang client JARs, native libraries, and asset indexes into an ASCII-safe local cache.
- **Multi-Segment HTTP Range & Parallel Downloads:** Splits large JARs (`>= 4 MB`) into 8 concurrent HTTP `Range` byte segments and downloads up to 32 parallel HTTP/2 streams with Windows Schannel fallback (`--ssl-revoke-best-effort`).
- **Low-Latency Network, Hardware Calibration & Auto Java 21:** Reads CPU cores, RAM, and DX12 GPU tier via `sysinfo` + headless `wgpu` to tune `-Xmx`, `G1GC`/`ZGC`, and `options.txt`; automatically installs verified Eclipse Temurin 21 if missing.
- **10 Mineral Themes, Live 3D Skin Viewer & Console Mode:** 7 dark + 3 light palettes, custom `#RRGGBB` accent contrast calibration, cursor-tracking 3D PNG skin preview (`64x64` / `64x32`, Slim & Classic arm alignment), Fullscreen Console (gamepad support), Discord Rich Presence, and live **English / Türkçe / Deutsch** localization.

## Legal, Scope & Safety Guarantees

- **Zero Copyrighted Game or Mod Files Bundled:** Official Mojang/Minecraft client JARs, asset packs, `.ogg` sounds, Java runtimes, mod loaders, OptiFine, and Modrinth projects are never committed to Git or embedded inside `basalt.exe`. Everything is fetched dynamically on the user's device from official upstream endpoints and verified cryptographically.
- **No Authentication Bypass (EULA Compliant):** Supports local singleplayer worlds (`--quickPlaySingleplayer`) and local/LAN `online-mode=false` development servers only. The Protocol 769 probe disconnects immediately on `EncryptionRequest (0x01)` and never bypasses Microsoft/Mojang account authentication.
- **Zero Telemetry:** No analytics, no tracking cookies, and no data collection. See [PRIVACY.md](./PRIVACY.md).
- **Unsigned Open-Source Build Notice:** Pre-release builds are built transparently by GitHub Actions CI without a commercial Authenticode certificate. Always verify downloaded binaries against `SHA256SUMS.txt`. See [SECURITY.md](./SECURITY.md).

## Build from Source

Prerequisites: **Rust (`cargo`)**, **Node.js (`npm`)**, and **Microsoft Edge WebView2 Runtime** (preinstalled on Windows 10/11). **Java 21 JDK** is detected automatically at runtime or auto-installed by Basalt.

```powershell
cd frontend
npm.cmd install
npm.cmd run build
cd ..
cargo test --workspace
cargo build --release --workspace
.\target\release\basalt.exe
```
